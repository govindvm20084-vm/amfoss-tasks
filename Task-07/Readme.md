The Discord bot I built is called Berry Broker. It was made using Python, with libraries such as os, random, datetime, discord.py, aiohttp, sqlite3, and python-dotenv.
Instead of splitting the commands into separate cogs, which was optional for this task, I kept the bot organized across two files.
Berry Broker adds a small pirate-themed economy to the Discord server it is added to. Every member starts as a rookie with a small amount of Berries. From there, users can claim their daily Berries using !setsail, check their !bounty, trade Berries with other members using !trade, gamble through !duel, raid another member's stash with !raid, or use !roast to get a random roast. There is also a !worstgeneration command that shows the leaderboard, and !logpose provides random information fetched live from the One Piece API.
Since !logpose depends on a free public API, I also added error handling so that if the API goes down or something changes on its side, the bot responds that the signal was lost instead of crashing.
Before starting this task, I had very little experience with making Discord bots. Learning how discord.py commands work, along with cooldowns, asynchronous functions, and API requests using aiohttp, was all fairly new to me.
Although I completed the task, I am still not completely comfortable with every part of the code and how everything works together. I plan to come back to it during my free time, practice with the code, and eventually get comfortable enough to understand and remember what each part does instead of just knowing that it works.
