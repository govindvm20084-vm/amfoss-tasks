I started by creating the basic structure of the website using HTML. I then used CSS to design the layout and make the interface responsive.

For the main functionality, I used JavaScript to fetch cryptocurrency data from the CoinGecko API. The API returns the data in JSON format, with information such as the coin's name, symbol, image, current price, market cap, and 24-hour price change.

I used JavaScript to read this data and display the relevant information on the webpage. I also added search functionality so that users can find specific cryptocurrencies instead of going through the whole list.

The data is fetched from the API rather than being manually entered, so the displayed prices and other market information can be updated with the latest available data.

.Fetching data from a REST API
.Working with JSON data
.Using JavaScript's fetch() function
.Handling asynchronous operations
.Accessing values from API responses
